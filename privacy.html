Ridvise Privacy Policy

Effective September 9, 2026

Ridvise Publisher ("the tool") is a private, single-user application operated by the owner of the Ridvise social media accounts. It exists only to publish Ridvise's own videos to Ridvise's own accounts.

Information we collect

When the account owner authorizes the tool with TikTok, TikTok provides an access token and basic profile information (open ID, display name, avatar). This is the only data the tool receives.

How it is used

The token is used solely to upload and publish videos to the authorized account. Profile information is used only to confirm which account is connected.

Storage and sharing

Tokens are stored locally on the owner's computer. No data is sold, shared, or transmitted to any third party. No data about other TikTok users is collected.

Deletion

Revoking the tool's access in TikTok settings, or deleting the local token, removes all stored data. Contact: anthateshomework@hotmail.com
